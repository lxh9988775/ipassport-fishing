① 画面 & 美术方向

风格：像素风（治愈系调性）。为什么换：240×320 无 PSRAM 小屏上，扁平插画放大后边缘发虚、颜色发飘反而显糙；像素风硬边 + 有限调色板在低分辨率屏上天生"对的"，是刻意的复古精致而非"没画完"。复用仓库 offline-pokedex 的 48×48 像素 sprite 管线，封面与上架图也统一走像素风。

sprite 方案（沿用仓库已验证的图鉴管线）

  • 图鉴项目用 48×48 预混合像素 sprite 嵌进固件（脚本生成 C 数组、无白边）——我们所有鱼/竿/漂/气泡走同一条管线。
  • 鱼 ≈ 28×18 像素，每鱼一套 ≤8 色调色板；生成方式：AI 出干净插画 → 缩放+调色板量化 → 导出 C 数组。
  • 动效（纯 LVGL 属性动画，零成本）：水波高光线每帧偏移、浮漂咬钩下沉抖动、鱼摆尾、上鱼缩小淡出+得分弹字。

② 核心玩法：星露谷绿条收线

菜单→ 待机→ 抛竿→ 等咬钩→ 收线小游戏→ 上鱼 / 跑鱼→ 结算

收线怎么做（把"无意义点击"换成真技巧）

  • 水下区一条竖直进度槽，槽内有一个绿色捕捉区；一条鱼在槽内上下乱窜（每条鱼有独立速度/跳动幅度/节奏）。
  • 按住 OK = 捕捉区上升；松开 = 下落。
  • 鱼在捕捉区内 → 进度条上涨；鱼在区外 → 进度下跌。
  • 涨到 100% = 钓上；跌到 0% = 跑鱼。全程不脱区 = 完美钓获，额外加分 + 图鉴标记。
这套机制把「反应测试」变成「手眼协调 + 读鱼节奏」的真技巧，且单键长按/松开即核心操作，与三键设备输入完全匹配。

⑥ 图鉴系统

  • NVS 存每鱼捕获计数 + 是否完美（24 种 → 每鱼 1 字节计数 + 1 bit，极省空间）。
  • 三键浏览：UP/DOWN 单击上/下一条、双击跳 ±5、长按跳场景首条；OK 看详情；长按 OK 返回（沿用图鉴项目交互范式）。
  • 详情页：sprite + 名称 + 体长 + 体重 + 稀有度 + 简介 + 已捕×N + 完美 ✓。
  • 未捕获显示「？？？」剪影，保留探索感；顶部显示「已收集 X/24」。

⑦ 蓝牙联机（Phase 4 · PoC 门控）

ESP32-C3 原生 BLE 5.0 GATT（≤3 并发）。仓库已有本项目实测过的双板 BLE 链路方案（对称发现 + NimBLE + 可靠传输层，约 60 KB 堆开销）。
  • 先做 PoC：设备发现 + 配对 + 双方实时分数同步，验证 BLE 与游戏同跑的内存余量。
  • PoC 通过 → 完整联机：60 秒「同场竞钓」，比谁钓得多/分高。
  • PoC 失败 → 降级为纯单机，联机标注「实验性」。
需两台设备真实验收（或用 Python 伪装机迭代协议），故排到最后阶段。

⑨ 升级预设 / 前向兼容（为后续版本留好接口）

原则：v2 只做 24 鱼 / 3 竿 / 3 关 / 单机，但数据结构与存档从第一行就按"以后会变大"来写，避免 v3 加内容时改存档格式、丢老玩家进度、或重排 ID 把图鉴搞乱。这一节会写进 Phase 1 验收清单。
① 存档版本化
整体 save_blob_t 含 magic + schema_ver；读档低版本走 migrate_save() 升级；损坏重置不崩。NVS 命名空间 fishing_v2（v3 自然隔离）。
② ID 稳定 + 容量预留
每种鱼/竿/关有不可变 ID，新增只追加不重排；图鉴容量 CODEX_CAP=64（现用 24）。遍历全按 *_COUNT，不写死 24/3/3。
③ 内容版本号
CONTENT_VER 与存档解耦：数值/简介微调只 bump 此号，不触发迁移；图鉴/关于页显示 v2.CONTENT_VER。
④ 功能位掩码
supported_features 位：单机/图鉴/关卡/蓝牙联机/每日挑战… 当前置前三位；联机落地置位，旧对端自动识别"不支持"。
⑤ 模式插件化
状态机保留 MODE 维度（现 MODE_SINGLE）；未来 MODE_VS / MODE_DAILY 并列挂 MENU 之后，不改动现有收线/结算。
⑥ 生成脚本参数化
sprite/字库生成以内容清单（yaml）为输入，加一种鱼 = 清单加一行 + 重跑脚本，自动扩，不需手工改数组。
  • ⑦ 多语言接缝：界面与简介走字符串表，content 表加 name_en/desc_en，未来加语言只加列。
  • ⑧ 上架/版本位：封面与「关于」页留版本位；更新走 project 700 的 --auto 流（不新建玩法）；changelog 独立字段，v3 起只补 changelog。
落地检查（Phase 1 验收）：save_blob 含版本且迁移可用 · 图鉴容量 ≥64 且 ID 不重排 · 遍历无魔法数字 · feature 位含联机/每日挑战预留 · 清单驱动生成。
