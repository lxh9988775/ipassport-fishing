设计理念 Why

先把"为什么这么做"讲清楚，再展开细节。

你的核心约束是 只有 3 个按键 + 一块 240×320 竖屏。这反而逼出了一种很舒服的玩法形态：

  • 城镇 = 节点地图，不是自由走位。3 键完全够用：上/确认进地点、下/切换地点、返回/开地图。不需要八方向摇杆。
  • 战斗 = 横版自动前进 + 自动普攻。玩家只负责"在正确时机按下"——放魔法、切伙伴、喝药。这正好对应 Idle Ascent 的"自动战斗 + 手动技能爆发"手感，单手可玩。
  • 自研魔法 = 三槽拼装，天然契合 3 键。形态 / 元素 / 修饰 三个词缀槽，每个键选一类，拼出独门魔法。把"复杂系统"藏进"简单操作"。
  • 成长不靠纯刷怪，靠"混合试炼"。晋升魔法师等级需要战斗+炼金+捕捉+采集组合完成，避免无聊 grind，也贴合"通过各种任务完成晋升"的诉求。
一句话定位：《宝可梦》的收集养成 + 《黑色五叶草》的"魔法帝"逆袭主线 + 《Noita/Ars Magica》的词缀拼装魔法 + 《Idle Ascent》的横版自动战斗，全部塞进 3 个键里。

硬件约束与美术基线 约束

机器现实（来自本项目固件基线）

  • ESP32-C3 · 8MB Flash · 无 PSRAM
  • ST7789P3 · 240×320 竖屏 · LVGL v9
  • 物理 3 按键（上/下/返回，长按=退出）
  • 已有 pet.c / pet_logic.c 框架可复用（LVGL 渲染、按键、存档）

因此定下的美术基线

  • 统一 16 色索引调色板，整包资源控制在 Flash 余量内
  • 角色/怪物精灵 24×24 或 16×16，每动作 4–6 帧
  • 人物头像贴图 32×32，菜单/对话/伙伴卡使用
  • 图集用 LVGL LV_IMG_CF_INDEXED_4BIT 压缩存储，省内存
  • 字体：子集中文点阵（沿用现有 fishing_cjk 生成管线）
无 PSRAM 意味着不能一次性解压大图。所有精灵走"小图 + 索引色 + 按需绘制"，这正是像素风的天作之合——反而比做精致 UI 更省。

3 键操作方案 核心

参考街机《PuLiRuLa》（正是 3 键：跳/杖击/召唤全屏）的按键哲学，映射到本机。

按键城镇 / 地图态横版战斗态菜单态
A 上/确认进入选中地点、确认对话、采集药草释放当前魔法/普攻（手动爆发窗口）确认选择、装备/使用
B 下/切换在地点节点间循环移动光标切换出战伙伴 / 切换魔法条上下切换选项
C 返回/地图打开世界地图、返回上级打开快捷菜单（喝药/魔法书/撤退）返回、关闭
A+C 长按退出当前界面 / 回主城（沿用现有 450ms 防抖长按规则）
抄自：《PuLiRuLa》三键设计——一攻击、一召唤（全屏清场）、一切换；以及《Idle Ascent》"自动战斗 + 手动触发技能爆发"。
我的自创：把"自研魔法"的 3 个词缀槽直接绑到 3 个键——拼装魔法时 A/B/C 各选一类，战斗里 A 就是放出刚拼好的魔法。操作即系统，零学习成本。

系统① 魔法师晋升 + 故事主线 需求1·7

从"新手魔法师"到"魔法帝"，7 阶晋升，每阶需通过一场混合试炼（不是单纯打怪）。

阶称号晋升试炼（需混合完成）解锁

4元素魔法师集齐 4 元素伙伴各 1 只 + 自研 1 个复合魔法元素亲和
5秘术师封印 1 只魔兽 + 炼制 1 瓶封印符封印系
6大魔导师征服龙巢 + 收服 1 条龙 + 通关 3 试炼塔龙骑

抄自：《霍格沃茨 Legacy》"完成多样化挑战才升级"的节奏（不纯靠打怪），以及《黑色五叶草》"魔法帝"称号作为终极目标。
我的自创：把晋升做成任务清单式试炼而非经验条——每阶给你 2–3 件不同性质的事（打/炼/捕/采），做完即晋。既呼应你"晋升不仅是打仗"的诉求，又天然串联起后面所有系统。

系统② 伙伴：精灵 / 魔兽 / 龙 / 兽娘 需求2

四类定位

类别定位稀有度倾向特色机制
精灵 Spirit辅助/Buff/控场较易捕低血高 utility，进化链短
魔兽 Beast坦克/近战中高防高血，可"封印"收服
龙 Dragon爆发/AoE稀有战力天花板，仅 Boss/事件出
兽娘 Beast-girl均衡/特有技中高专属技能；部分需非战斗魅惑捕获

稀有度 5 档（影响出现率 & 捕获难度）

N 普通R 精良SR 稀有SSR 史诗UR 神话

随机性设计（捕获即"开盲盒"）

  • 个体值 IV：捕获时随机 1–5 星（影响种族值成长）。
  • 技能池：种族固定技 + 随机 1–2 个额外技（从该类技能池抽取）。
  • 异色 Shiny：1/256 概率，独立调色板 + 属性加成 + 专属闪光动作。
  • 元素亲和：随机微偏，影响该伙伴某元素伤害 ±10%。

捕获公式（直接复用宝可梦成熟模型）

捕获率 = 基础(物种) × (1 − 2/3·剩余HP%) × 球倍率 × 状态倍率

  • 满血约 15%，残血(1HP)约 70%；睡眠/麻痹 +20%，其它异常 +10%。
  • 球档：普通×1 / 精良×1.5 / 超级×2.5 / 传说×4（UR 必需）。
  • 失败不消失：对方继续行动——这是紧张感的来源（宝可梦设计精髓）。
  • 图鉴：捕获/见过即登记，登记越多，"临界捕获"概率越高（彩蛋向）。
抄自：宝可梦 catch rate 公式、进化（等级进化 +25% 属性 + 新技能 + 可取消）、异色、图鉴临界捕获；龙/兽娘分层参考《怪物猎人》《明日方舟》。
我的自创：①兽娘"魅惑捕获"——部分兽娘不能靠打残血抓，要送礼物/完成好感事件（贴合人形伙伴的叙事）；②把"封印"作为魔兽专属收服动词，呼应需求④的封印装备线。

系统③ 药草采集 + 炼金术 需求3

药草采集

  • 地图节点散布药草点，靠近按 A 采集（类暗黑 4 路边香草）。
  • 药草按元素分：火焰草/月光花/雷鸣根/清风叶/圣百合/暗影苔。
  • 季节/时段刷新不同，制造"再来的理由"。
  • 采集本身也是晋升试炼的计数项。

炼金台（主城建筑）

  • 草药 + 怪物材料 → 药剂 / 元素精华 / 封印符 / 捕获球。
  • 配方随进度解锁（试炼、探索、NPC 赠予）。
  • 产物举例：回复药剂、魔力药水、火属性精油、封印符、精灵球。
  • 炼金成品既是消耗品，也是装备打造的材料。
抄自：《Atelier》炼金做一切（比买更好更可定制）+《暗黑4》草药→炼金师→药剂/香薰的材料链路。
我的自创：炼金产物直接反哺另外两条线——药剂用于战斗续航、精油/封印符用于装备打造的词条偏向、精灵球用于捕捉。让"采→炼→用"形成闭环，而不是孤立小游戏。

系统④ 装备打造（已为你简化） 需求4

你说"不要太复杂"，所以我砍掉了暗黑那套几十词缀的 soup，改成"1 主倾向 + 2 随机副词条"模型。

部位（只留 4 个，够用不烦）

部位主作用可主倾向
法杖（主手）魔法威力攻击 / 元素攻击 / 回复 / 封印
法袍（防具）生存防御 / 回复 / 封印抗性
饰品功能元素攻击 / 防御 / 施法加速
靴机动闪避 / 先手 / 回复

打造流程（3 步）

  1. 选底材（白板装备，决定部位）。
  2. 选主倾向：攻击 / 元素攻击 / 回复 / 防御 / 封印（你点名的 5 类）。
  3. 投入材料（怪物材料 + 炼金精油）—材料元素偏向该倾向，再随机 2 条副词条。

副词条池（精简到 ~12 条，可读可建）

攻击+15%火焰伤害+20%每回合回血受击减伤封印抗性施法加速暴击+10%命中+1MP回复元素穿透护盾+1经验+5%

抄自：《暗黑》词缀"修饰器"思想（属性/机制/技能三类），但只保留其骨架。
我的优化（按你要求做减法）：① 主倾向把"你想强调的方向"显式化，避免暗黑式随机到怀疑人生；② 副词条封顶 2 条 + 小池子，刷装备有正反馈但不肝；③ 封印做成独立倾向与抗性，呼应"封印兽/魔兽"玩法，这是原版没有的缝合。

系统⑤ 像素风 + 人物头像贴图 需求5

  • 统一像素美学：16 色板、硬边、无抗锯齿，保证全游戏视觉一致。
  • 人物头像贴图（关键需求）：每个可交互角色（玩家"小锐"、导师、炼金娘、兽娘伙伴等）都有独立 32×32 头像，用于对话、伙伴卡、图鉴。
  • 主角"小锐"沿用你短剧里的虚拟角色，保持 IP 一致。
  • 头像与战斗精灵同源绘制，避免"菜单一张脸、战斗另一个人"。
头像资源量可控：NPC 约 8–12 张、伙伴约 16–24 张，每张 32×32×4bit ≈ 0.5KB，整包 < 20KB。完全在无 PSRAM 预算内。

系统⑧ 自研魔法（核心创新） 需求8

最值得做的点。用"形态 + 元素 + 修饰"三槽拼装，每个键选一类，简单但有深度。

槽（绑键）可选词缀作用
形态 Form A弹射 / 锥形 / 领域 / 自身 / 链决定魔法怎么打出去、打哪
元素 Effect B火 / 水 / 风 / 雷 / 光 / 暗 / 治疗 / 封印 / 护盾决定伤害属性与效果
修饰 Meta C强化 / 扩散 / 穿透 / 减速 / 灼烧 / 连发改伤害、范围、附加异常

拼装示例

  • 弹射 + 火 + 扩散 = 火焰散射（清小怪）
  • 领域 + 暗 + 封印 = 暗影牢笼（控场+封印魔兽）
  • 自身 + 治疗 + 连发 = 回春术（持续回血）
  • 链 + 雷 + 穿透 = 雷 Chain（多目标爆发）

文字词条拼接（进阶）

探索中收集词条碎片（如「爆裂」「寒霜」「回响」「禁锢」），可在魔法书里像拼乐高一样塞进修饰槽，拼出配方命名并保存，形成你的独门魔法库。高阶修饰（如"回响=连锁触发"）需晋升解锁。

抄自：①《Noita》法杖=武器、法术=弹药、修饰从左往右作用；②《Ars Magica / Pathfinder 词缀法术》的"形态+效果+元"三段模型；③《Magicka》元素相生相克。
我的自创：把这三段模型直接绑到 3 个物理按键——拼魔法时用键选类，战斗里按键即放。并加入词条碎片收集+命名保存，让"自研"有成长感和收藏感，而不只是临时拼一下。

系统⑨ 战斗 & 魔法专属动作 需求9

你强调"不能太粗制滥造"——所以每个实体/技能都要有独立动画与 VFX，不是换色贴图。

动画规范（每个角色/怪物必备帧组）

动作帧数说明
Idle 待机4呼吸/飘浮微动
Walk 行走4横版迈步
Attack 普攻4杖击/爪击专属姿态
Cast 吟唱4举杖蓄力 + 光点聚拢
Skill 大招6专属演出（龙=展翼吐息，兽娘=突进斩）
Hit 受击2后仰闪白
Faint 倒下3倒地/消散

魔法 VFX 分层（保证不"换色了事"）

  • 施法姿态：玩家举杖动作随元素变色（火=红焰、水=蓝波、光=金环）。
  • 弹道/范围：火=拖尾火星、水=水泡弧线、雷=折线、风=透明气旋、暗=紫黑裂痕。
  • 命中表现：火=爆燃、水=溅射、雷=麻痹电花、暗=封印锁链缠绕。
  • 异色专属：Shiny 伙伴释放时附加金粉拖尾，一眼可辨。
实现上：精灵用 LVGL lv_img 序列帧 + 简单位移/缩放/透明度 tween 即可做出"有演出感"的动作，无需骨骼动画，省资源且可控。
