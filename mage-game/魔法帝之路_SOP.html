① 游戏总览

一句话：你扮演一名见习魔法师，踏平五道封印、收服魔物伙伴、研习 135 种魔法，最终登顶「魔法帝」。

50+可遇魔物种类（11 基础 + 39 扩充）
135魔法组合数（3 形态 × 9 元素 × 5 修饰）
30随机副本 / 地下迷宫 / 古代遗迹
7魔法师阶位（见习 → 魔法帝）
5主线章节 · 每章 1 体 BOSS
3操作键（A/B/C）

定位与设计基调

  • 平台：单文件 index.html，浏览器 / 手机直接打开即玩；进度自动存 localStorage（支持导出 / 导入 JSON 存档）。
  • 节奏：升级曲线刻意放慢（约 1.8 倍），靠副本与 BOSS 的额外经验推进；装备门禁——没装备时打章节 BOSS 会非常吃力，逼你做装备。
  • 画风：八方旅人 / HD-2D 像素风，深靛紫底 + 描金 UI + 像素怪物立绘（统一规范驱动，50 怪共用一套立绘生成器）。
  • 版本注：文件标题里写的版本号是 v6.4，与本次交付的实际代码 v7.4.4 不一致；以交付版本为准。

② 剧情主线 · 五道封印

主线采用「章节门禁」：必须击败上一章 BOSS，才能解锁并进入下一章。每章首次进入播入场剧情，击败 BOSS 播通关剧情。

击败每章 BOSS 后会掉落高品质装备 + 2 魔晶 + 2 捕捉球 + 1 封印卡，并解锁下一章。终章 BOSS 倒下，主角从「见习生」正式成为踏过五道封印的魔法师。

职业晋升（独立于战斗）

阶位由 魔法学院 → 职业晋升考核 推进，条件是击杀数达标 + 完成足够公会委托（详见 ⑥ 学院 / 公会）。战斗胜利不会自动晋升，避免「打几仗就自动升级」让晋升形同虚设。

③ 操作说明（3 键）

A = Z确定 / 攻击 / 进入 / 施法
B = X切换 / 选择下一项
C = C菜单 / 返回 / 道具
  • 键盘映射：Z=A、X=B、C=C（另 Enter=A、方向键左右上下 = B/C 切换）。
  • 手机：直接点屏幕下方三个按钮 A 确定/攻击 / B 切换 / C 菜单/返回。
  • 绝大多数界面遵循「B 选择、A 确定、C 返回」三键逻辑；战斗时 C 打开道具栏（含捕捉球 / 封印卡）。

④ 核心玩法循环

  1. 城里整备：魔法学院学魔法 / 升级、锻造房造装备、住宅炼金造药水与捕捉道具、黑市补素材。
  2. 出野外远征：选章节 → 打 10 波（第 5 波精英、第 10 波 BOSS），途中插探索事件（宝箱 / 陷阱 / 泉水 / 药草）。
  3. 战斗：法师站桩远程输出，普攻 / 魔法 / 伙伴协同 / 用药 / 捕捉球收服；元素相性破防是核心技巧。
  4. 成长：击杀拿经验升级、金币、材料、药水；满足条件后回城晋升阶位 / 冒险者等级。
  5. 深化：用魔石升级魔法、用材料炼高级道具、收服并进化伙伴、刷随机副本拿稀有装备与魔石。
挂机友好：可开自动战斗与自动捕捉（系统菜单里切换）。自动模式下编队魔法轮流放，虚弱可捕怪会自动扔球 / 卡；关掉自动捕时，被锁血的怪会主动逃走清场，不会卡死。

⑤ 新手推进 SOP（照着走即可通关主线）

  1. 开始：标题页选「新的旅程」→ 命名（B 切换 7 个预设名，A 确定）→ 进入魔法小镇。
  2. 首战前整备：去魔法学院花 45 金「学习属性魔法」至少学 1 门；去锻造房升 1 级武器（+攻击）。
  3. 试炼森林：城镇地图选「野外试炼 → 试炼森林」(建议 Lv1+)，A 出发。自动/手动打完 10 波，第 10 波是哥布林王。
  4. 捕捉练习：途中把史莱姆 / 猫灵打到残血，C 开道具 → A 投捕捉球收服（猫灵全图小概率出没，是稳定伙伴来源）。
  5. 回城晋升：击杀够了去冒险者公会接委托、魔法学院参加「职业晋升考核」升阶位（见习 → 初级魔法师）。
  6. 解锁下一章：拿到哥布林王掉落后，野外试炼里下一章（幽暗洞窟）自动解锁；重复 ②~⑤ 直到五章通关。
  7. 后期深化：刷 30 张随机副本拿古代魔石，在魔法升级里把古代级魔法升满；收齐 50 怪图鉴；通关遗迹秘境(连过 3 层)拿豪华奖励。
装备门禁提醒：每章 BOSS 血量约为小怪的 7.5 倍、攻 1.85 倍，且有 5 层破防盾。没武器/护甲就硬刚会很苦——打 BOSS 前务必先锻造 / 攒一套 BOSS 掉的高品质装备。

⑥ 场景地图（魔法小镇 + 功能）

城镇是 hub：上方一行 7 个地点，下方 8 张功能卡。B 切换、A 进入、C 在地图 / 功能栏之间切换。

地点（地图模式）

  • 魔法学院：魔力修行(+上限)、学习属性魔法(随机一门)、职业晋升考核。
  • 野外试炼：5 章 + 遗迹秘境 + 随机副本入口（主线推进核心）。
  • 冒险者公会：接委托、交付、升冒险者等级(F→S)。
  • 住宅：休息(满血满蓝)、炼金台、魔法研究。
  • 锻造房：锻造武器(+攻)、法袍(+血上限)。
  • 魔法黑市：买月光草/兽骨/魔晶/封印卡/魔法书。
  • 魔物图鉴：收录进度、出没、捕捉条件、天赋/特性/进化。

功能卡（功能模式）

  • 角色 STATUS：看属性、装备、出战魔法。
  • 伙伴 PARTNERS：出战 / 进化 / 放生。
  • 魔法书 BOOK：节点图管理已学魔法、编出战队列、研究新魔法。
  • 炼金 ALCHEMY：用药草/兽骨/魔晶炼药水、球、卡、魔石。
  • 背包 BAG：按分类(药品20/材料40/魔石/道具)浏览全部物品。
  • 装备 EQUIP：装备 / 替换武器·护甲·饰品。
  • 魔法升级 MUPGRADE：耗魔石+金币升魔法等级。
  • 系统 MENU：自动战斗 / 自动捕捉 / 音效 / 难度 / 存档导入导出 / 重开。

⑦ 魔法系统（三槽组合）

每门魔法 = 形态 × 元素 × 修饰 三个槽位。3 形态 × 9 元素 × 5 修饰 = 135 种组合，再按修饰槽位分 5 个阶级。

形态 FORMS

  • 弹：单体远距
  • 光束：直线远距
  • 爆发：范围

元素 ELEMS（9）

  • 火 / 水 / 雷 / 风 / 土 / 冰 / 光 / 暗 / 虚无
  • 各有威力系数，影响相性与伤害

修饰 MODS（5）

  • 普通 / 强力(×1.5耗魔+) / 广域(命中全体)
  • 连发(最多3目标) / 古代(×2.4耗魔极高)

阶级与「学得起用不起」设计

阶级由修饰槽位决定：TIER_NAMES = 初级 / 中级 / 高级 / 国家级 / 古代。低等级也能研究最高级魔法，但耗魔巨大放不出来——魔力上限随等级成长，这就是代价。

  • 研究新魔法：BOOK → 节点图选「+ 研究新魔法」→ CRAFT 三槽自由拼装（A 切槽、B 换选项、C 装配录入魔法书）。
  • 魔法等级：RESEARCH(住宅) 耗月光草×2+兽骨×2 提升单门等级（等级越高成功率越低）；魔法升级 MUPGRADE 耗魔石+金币直接升（高阶级需对应魔石）。
  • 出战编队：BOOK 里 A 加入 / 移出，最多 4 门；战斗中自动模式按编队轮流放。
  • 耗魔公式：3×形态系数×修饰耗魔 + 阶级×8（初级≈3，古代弹≈39+），等级低时高阶魔法放不出。
魔石（stones[1~4]）对应 中级/高级/国家级/古代魔石，是魔法升级货币：可炼金造、副本/宝箱掉落、BOSS 击杀附带。

⑧ 捕捉与伙伴系统

两类捕捉道具

  • 捕捉球（orb）：成功概率 = 怪稀有度上限 × 虚弱系数；N 满血约 37% → 残血 95%；UR 满血仅 11%（克制高稀有）。
  • 魔法封印卡（seal）：固定 75%~95%（血越少越高），无视稀有度压制，专治 SSR/UR 与浮空遗迹类怪。炼金需兽骨×2+魔晶×1。
  • 伙伴特性幸运 +10% / 柔软 +15% 提升捕捉概率。
捕捉门槛：怪可分两类——① 任意血量+持有对应道具即可捕（球类）；② 必须压到指定血线以下才能捕（如霜牙雪狼需血<40%、遗迹魔像<25%、远古怨灵<30%）；③ 部分怪只能用封印卡（冰晶灵、遗迹魔像、远古怨灵、幼龙、符文傀儡等）。BOSS 不可捕捉。

伙伴养成

  • 出战：PARTNERS 页 A 设当前出战位（出战伙伴会在战斗里协同攻击）。
  • 天赋技能：利爪/疾风/毒牙/吸血/余烬/霜咬/守护（出战命中或回合生效）。
  • 特性：凶暴/坚壁/灵巧/沉静/幸运/柔软/贪吃（被动，收服时随机 1 条）。
  • 资质 ivs：攻/防/速 0~15，总和 26~45 评级 B/A/S；影响伙伴面板。
  • 进化：达等级阈值后 PARTNERS→菜单→进化，改名(如·月影/·泰坦)并提升资质与稀有度上限。
  • 收服优先级：自动捕捉优先选「图鉴未收录 > 非猫灵 > 血越低」的怪，保证收集多样性。

手动捕捉：战斗中把怪打到残血 → 按 C 开道具栏（有可捕残血怪会自动跳到对应球/卡）→ A 投掷收服。

⑨ 装备 / 物品 / 炼金

装备（三槽，品质=稀有度）

  • 武器：+攻击（如星陨神杖）。
  • 护甲：+减伤（如龙鳞法袍）。
  • 饰品：+法强%（如贤者之石）。
  • 品质 N / R / SR / SSR / UR；BOSS 必掉高品质。
  • 锻造房：武器每级 +2 攻、法袍每级 +8 血上限。

物品（背包按分类浏览）

  • 药水 20 种：回血/回蓝/解毒/各属性免疫/攻击·法强增益/经验/不死鸟之羽(复活)等，含普通~传说稀有度。
  • 材料 40 种：月光草/兽骨/魔晶/各类怪掉落素材，分 普通16·稀有14·史诗7·传说3。
  • 魔石 / 道具：捕捉球、封印卡、月光草、兽骨、魔晶、体力药水单独计数。

⑪ 战斗机制

战斗结构

  • 远征：每章 10 波，第 5 波精英、第 10 波 BOSS；波间插探索事件。
  • 副本：达设定轮数即通关发奖，绝不刷 BOSS。
  • 精英：血量×2.2、攻×1.5、2 层破防盾。
  • BOSS：约 7.5 倍血、1.85 倍攻、5 层破防盾、随机 2 魔抗、蓄力大招、半血狂暴、每回合回血。

元素相性（破防核心）

  • 命中弱点属性 → 伤害 ×1.5 + 削 1 层盾。
  • 盾空 = 破防：硬直 + 所有来源伤害 ×1.4。
  • BOSS 随机 2 个魔抗属性（不与弱点重叠）：该属性伤害 ×0.45，挂机无脑轮放会砸在抗性上 → 手动看抗性换属性才有优势。
  • 不破盾打 BOSS 几乎白费（它每回合回血），逼你走「弱点破防循环」。

回合流程（手动）

  1. 菜单选「攻击(普攻) / 魔法 / 道具(C 开)」→ A 行动。
  2. 行动后伙伴协同出击（技能/特性生效）。
  3. 清场则胜利结算；否则进入敌方回合，怪物走近→冲锋伤害→退回。
  4. 血量归零 = 力竭，战斗结束回城（不删档）。
BOSS 大招（蓄力中）记得破盾或防御化解；守护技能、铁壁药剂、不死鸟之羽（复活）是硬扛资本。BOSS 战胜利后会显示整体计算画面（总击杀/金币/经验/素材 + BOSS 专属掉落），停留约 2 秒再回城。

⑬ 数据附录 & 系统参数

阶位与晋升条件

  • 阶位：见习→初级→中级→高级→大魔法师→魔导师→魔法帝
  • 击杀门槛：6 / 16 / 30 / 48 / 70 / 96 / 无尽
  • 晋升还需：完成公会委托数 ≥ 当前阶位+1

难度档（系统菜单切换）

  • 轻松：怪血/攻×0.7、受伤×0.7
  • 普通(默认)：×1.0
  • 困难：怪血×1.5、攻×1.3、BOSS攻×1.5、受伤×1.25
  • 炼狱：怪血×2.1、攻×1.6、BOSS攻×1.9、受伤×1.4

升级 / 经济曲线

  • 升级所需经验：16 + 等级×11（刻意放慢约 1.8 倍）。
  • 每级 +6 血上限、+3 蓝上限、回满状态。
  • 小怪难度微调：血量/攻击 ×1.05（用户反馈略简单后调整）。
  • 探索事件概率 45% 且每轮保底 1 次（第 4 波前强制来一次），含宝箱/陷阱/泉水/药草。

存档与健壮性

  • 自动存 localStorage('mage_save_v1')，支持系统菜单「导出 / 导入」JSON 存档。
  • 读档经 normalizeState() 全字段净化（数值 NaN/null/越界 → 默认值），所有读取走安全助手（slv/stoneN/slvSet），旧档 / 脏档不会崩溃。
  • 战斗崩溃时屏幕顶部显示红色错误条（6 秒自动消失），不会卡死。
