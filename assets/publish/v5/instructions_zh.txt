离线玩法，无需配网，开机即玩。按键：UP / DOWN 选择，OK 确认或操作，长按 OK 返回。

1. 长按 OK 打开菜单，光标移到「钓点」按 OK，上下选钓场、再按 OK 进入标点页；左右切换标点，看清「出鱼」提示后按 OK 确认。
2. 回到钓场按一下 OK 抛竿，浮漂落水后等咬钩；出现「咬钩了！按 OK 提竿」时立刻按一下 OK。
3. 收线时按住 OK 让捕捉区上浮、松开下沉，把捕捉区压在鱼身上，进度涨满就上鱼；全程没脱区是「完美钓获」。
4. 长按 OK 的菜单可换鱼竿、饵料、钓场，翻看图鉴或关声音；图鉴上下翻、OK 看详情，详情里记着首次钓到的日子和标点。
5. 钓场随钓获数逐步解锁，未解锁会写明还差几条；得分与图鉴进度自动保存，下次开机接着玩。
